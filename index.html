App Settings

Temibiyi Herbs Manager is designed to run on iPad, iPhone and laptop. This version is offline-first and ready for cloud synchronization.

Cloud Synchronization

Cloud sync requires connecting the app to a database account. The app structure is prepared for this, but no private cloud credentials are embedded in this downloadable version.

Recommended final setup: one login for Admin, separate Cashier accounts, and one shared online database so the same sales and stock appear on every device.
